## Preserve these teaching points

Manuscript: [chapter-13-smart-pointers](../../../book-pdf/src/chapter-13-smart-pointers.md).

- Teach Rc and RefCell as explicit choices for shared ownership and interior
  mutability; later BFMs, ConfigDb entries, and subscriber storage rely on these
  concepts.
- Keep examples and any reference-count or panic output tied to the runnable
  files. Framework task panics fail the test rather than unwinding across the
  simulator FFI.

Read this crate’s source and this README before changing a quoted
figure or behavioral claim; keep the source, figure map, and transcript aligned.
